# dsh-workbench-tags

个人工作台标签插件：创建与管理标签，为站点等业务提供标签归类

## 安装

```sh
dsh plugin --profile web add dsh-workbench-tags
```

安装或升级后按 DSH 提示重启/刷新。

标签被删除后，站点等引用它的条目会失去该标签，但条目本身保留。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
