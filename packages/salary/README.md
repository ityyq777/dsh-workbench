# dsh-workbench-salary

个人工作台工资插件：按发薪日期记录工资构成、扣款与实发

## 安装

```sh
dsh plugin --profile web add dsh-workbench-salary
```

安装或升级后按 DSH 提示重启/刷新。

只存本机 SQLite，不存姓名与工号，不参与云同步；不限月结，日结多笔也可按日期记录。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
