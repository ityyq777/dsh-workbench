# dsh-workbench-sites

个人工作台站点插件：目录树、链接与标签

## 安装

```sh
dsh plugin --profile web add dsh-workbench-sites
```

安装或升级后按 DSH 提示重启/刷新。

标签功能在检测到 dsh-workbench-tags 已安装时显示；未安装时站点仍可正常使用目录与链接。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
