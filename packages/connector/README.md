# dsh-workbench-connector

个人工作台连接器插件：RSS/Webhook 内容接入，来源定义、条目与运行记录

## 安装

```sh
dsh plugin --profile web add dsh-workbench-connector
```

安装或升级后按 DSH 提示重启/刷新。

只保存来源定义与拉取到的条目，不代理浏览外部页面；凭据优先存保险箱。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
