# dsh-workbench-contacts

个人工作台联系人插件：本地联系人、分组、多值字段与 vCard 导入导出

## 安装

```sh
dsh plugin --profile web add dsh-workbench-contacts
```

安装或升级后按 DSH 提示重启/刷新。

联系人只存本机 SQLite；vCard 导入导出按文件和文本处理，不上传。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
