# dsh-workbench-danmaku

个人工作台弹幕插件：把自建弹幕轮播在整个 DSH 界面，并可叠加到整个桌面

## 安装

```sh
dsh plugin --profile web add dsh-workbench-danmaku
```

安装或升级后按 DSH 提示重启/刷新。

桌面透明层依赖 Electron 外壳；弹幕库只存本机，不上传也不参与云同步。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
