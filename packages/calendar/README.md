# dsh-workbench-calendar

个人工作台日历插件：本地日历、事件、参与人与提醒

## 安装

```sh
dsh plugin --profile web add dsh-workbench-calendar
```

安装或升级后按 DSH 提示重启/刷新。

事件与提醒存本机；不订阅外部日历协议。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
