# dsh-workbench-tasks

个人工作台任务插件：任务树、优先级、截止日、时间线与重启

## 安装

```sh
dsh plugin --profile web add dsh-workbench-tasks
```

安装或升级后按 DSH 提示重启/刷新。

任务、标签、站点数据都保存在宿主 SQLite；卸载插件不删数据。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
