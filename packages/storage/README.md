# dsh-workbench-storage

个人工作台储物插件：名称、品牌、单位、库存文本与标签

## 安装

```sh
dsh plugin --profile web add dsh-workbench-storage
```

安装或升级后按 DSH 提示重启/刷新。

管理物品库存文本台账，不上传或下载文件字节；卸载插件不删数据。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
