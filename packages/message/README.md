# dsh-workbench-message

个人工作台消息插件：统一消息发送入口、收件箱、未读统计与提示音

## 安装

```sh
dsh plugin --profile web add dsh-workbench-message
```

安装或升级后按 DSH 提示重启/刷新。

消息只保存在本机，不参与云端同步，也不进入备份导出；已读消息默认 30 天后清理。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
