# dsh-workbench-mail

个人工作台邮件插件：IMAP 收信头、SMTP 发信、保险箱托管密码

## 安装

```sh
dsh plugin --profile web add dsh-workbench-mail
```

安装或升级后按 DSH 提示重启/刷新。

不下载完整正文与附件；发信仅纯文本，需要先安装 dsh-workbench-vault 保存密码。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
