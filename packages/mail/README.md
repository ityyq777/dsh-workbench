# dsh-workbench-mail

个人工作台邮件插件：安全 IMAP 收信、文件夹与已读同步、附件按需下载、草稿与 SMTP 回复转发

## 安装

```sh
dsh plugin --profile web add dsh-workbench-mail
```

安装或升级后按 DSH 提示重启/刷新。

保险箱随邮件安装；首次使用仍需初始化、解锁并绑定邮箱授权码。邮件账户仅保存 secretId。

## 兼容性

- DSH：`>=0.2.0-rc.1 <0.3.0`
- Node：`>=22.5`
